投稿詳細ページで使える「投稿が指定カテゴリーに属する」条件を追加しました。

- カテゴリーを選択し、所属する投稿で IF、所属しない投稿で ELSE を表示できます。
- 「条件を反転（NOT）」を有効にすると、「属していない」を条件にできます。
- 複数選択時は「いずれかに属する」、NOT では「いずれにも属していない」と判定します。
- 判定対象は表示中の通常投稿に直接付与されたカテゴリーです。通常投稿の詳細ページ以外や対象カテゴリーの削除時は、両分岐とも表示しません。
- 日本語翻訳、操作手順、条件判定と保存再読込のテストを更新しました。

添付の **od-conditional-blocks.zip** を WordPress のプラグイン追加画面からアップロードしてください。
