「特定の投稿・固定ページ」条件と、入力欄内のトークン表示を追加しました。

- 公開済みの投稿・固定ページを検索し、指定したページだけで IF を表示できます。複数選択と NOT に対応します。
- 対象は ID で保存するため、タイトルやスラッグの変更後も判定を維持します。対象が削除・非公開になった場合は、両分岐とも表示しません。
- カテゴリー・タグ・カスタムタクソノミー・投稿タイプなどの選択済み項目を、入力欄内にトークンとして表示します。その場で選択を解除できます。
- 既存の保存済み条件は維持し、候補にない自由入力による項目の追加は行いません。
- 日本語翻訳、操作手順、条件判定と選択・削除・保存再読込のテストを更新しました。

添付の **od-conditional-blocks.zip** を WordPress のプラグイン追加画面からアップロードしてください。
