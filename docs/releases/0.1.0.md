OD Conditional Blocks の初期開発版です。WordPress の投稿・サイトエディターで、サーバー側の条件によって IF / ELSE の内容を切り替えられます。

### 主な機能

- 条件分岐・IF・ELSE の3ブロック。新規挿入は IF のみ、ELSE は必要なときに追加できます。
- ページ種別・特定アーカイブの18条件、AND / OR / 条件単位の NOT。
- 非選択側の子ブロックは PHP コールバック実行前にレンダリングを中断します。
- 編集用の IF / ELSE / 両方の切り替え、リストビュー連動、条件候補の検索。
- 英語・日本語、保存・再編集・Undo/Redo・ネストに対応。

### 動作要件・検証

WordPress 6.8 以上、PHP 8.1 以上。WordPress 6.8 / 7.1.4 と PHP 8.1.34 で、各17件・95アサーションの PHP 結合テスト、各6件の Playwright E2E が成功しています。JS ユニット5件、WPCS、JS lint、ビルド、配布 ZIP も確認済みです。

### インストールと制限

添付の **od-conditional-blocks.zip** を WordPress のプラグイン追加画面からアップロードしてください。GitHub の自動生成ソースアーカイブには実行時依存が含まれません。

表示制御専用です。アクセス認可・機密保持には使用しないでください。プラグイン停止時も子コンテンツは残り、IF と ELSE の両方が公開表示される可能性があります。未設定・不正な条件では両分岐とも表示しません。

手動スクリーンリーダー確認と、開発依存の npm audit 指摘への対応は継続課題です。詳しい操作手順・検証範囲は同梱の docs と README を参照してください。
