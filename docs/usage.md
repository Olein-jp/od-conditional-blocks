# 利用手順

1. 投稿またはサイトエディターのテンプレートに「条件分岐（Conditional）」を追加する。初期状態は IF のみ。
2. インスペクターで最初の「表示しているページの種類」を設定する。未設定時は公開ページに何も出ない。
3. IF に条件成立時のブロックを置く。不成立時の内容が必要な場合だけツールバーの「ELSE を追加」を押す。
4. IF／ELSE／両方で編集対象を切り替える。リストビューから非表示側の子を選んでもその分岐が表示される。
5. 必要なら条件を追加し、AND／OR や条件ごとの NOT を設定して保存する。

ELSE 削除時は確認が表示され、Undo/Redo で取り消し・やり直しができる。IF は構造上必須。条件分岐全体を削除すると子も削除される。

## カテゴリーだけの案内

サイトエディターのアーカイブテンプレートに Conditional を置き、カテゴリーアーカイブを選び、IF に案内を書く。ELSE は追加しない。カテゴリーでは案内が出て、タグなどでは出ない。サイトエディターの閲覧中クエリーがカテゴリーでなくても IF は編集できる。

「特定のカテゴリー」は現在要求されたアーカイブの対象を判定する。クエリーループ中の投稿に付いたカテゴリーを判定するものではない。

## 投稿詳細ページでカテゴリーによって分岐する

1. 投稿本文または投稿詳細テンプレートに「条件分岐」を追加する。
2. 条件で「投稿が指定カテゴリーに属する」を選び、「カテゴリーを追加」から対象を選択する。
3. IF に所属する場合の内容を配置する。所属しない場合の内容は ELSE に配置する。
4. 「所属していない」を IF 側の条件にする場合は「条件を反転（NOT）」を有効にする。

複数選択時は、いずれかに属すれば一致する。NOT を有効にすると、選択したカテゴリーのいずれにも属していない投稿に一致する。直接付与されたカテゴリーだけが対象で、子カテゴリーから親カテゴリーへの所属は推定しない。

判定対象は表示中の通常投稿（投稿タイプ `post`）。クエリーループ内でもメインリクエストの投稿を判定する。固定ページ・アーカイブ・検索結果などの投稿詳細ページ以外、対象の未選択・削除時は、NOT の有無にかかわらず、この条件を含む条件分岐全体で IF／ELSE のどちらも出力しない。

## 制約

- 表示制御専用。機密情報や会員限定情報のアクセス認可には使用しない。
- プラグイン無効化時も投稿・テンプレート内に子コンテンツが残る。その結果、IF と ELSE の両方が公開表示される可能性がある。
- 未設定、不正な値、不明な条件、削除済みの対象は両分岐を出さない。
- 「条件を有効にする」をオフにすると IF を常時表示する。編集表示モードとは別の保存設定。
- 表示モードは保存されず、再編集時は IF に戻る。表示切り替えだけで未保存変更を作らない。
- 条件に個人情報やログイン状態は含まれない。通常のページキャッシュをパージする必要はサイト側の運用に従う。
- 外部プラグインによるレンダーフィルターの上書きは、分岐制御に影響する場合がある。
